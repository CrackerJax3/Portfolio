MakeyMakey Vertical Plotter

Project Details

Modified the open-source polargraph code to fit the memory constraints of the Arduino Leonardo, then designed a custom shield for the back of the MakeyMakey board — making vertical plotting accessible for young Makers without requiring a separate microcontroller.

Highlights

  • Ported polargraph firmware to Arduino Leonardo
  • Custom MakeyMakey shield design
  • Open-source · maker education
  • Vertical wall plotter
