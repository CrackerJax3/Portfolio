SawySawy OpenCV Robot Hand

Project Details

Built an OpenCV Python application to control a robot hand designed using a MakeyMakey as the microcontroller. The hand mirrors finger movements captured by a webcam in real time.

Highlights

  • OpenCV real-time hand tracking
  • MakeyMakey microcontroller
  • Laser-cut hand design
  • Python · computer vision
