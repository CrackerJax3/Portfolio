SawySawy CNC Plasma Cutter

Project Details

Designed and built a functional CNC plasma cutter from scratch using recycled 3D printer linear rails and motion components, with a MakeyMakey as the motion controller. Demonstrates end-to-end machine building — mechanical design, electronics integration, and CAM programming — from salvaged parts.

Highlights

  • Recycled 3D printer linear rails
  • MakeyMakey motion controller
  • GRBL / CAM programming
  • Full mechanical & electronics build
